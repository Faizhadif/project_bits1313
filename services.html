The items below are organized by core components: workstations, networking, and the operating environment for sessions and billing.

Proposed hardware

Client workstations

CPU i5/Ryzen 5, 16GB RAM, SSD, monitor 24".

Router + core switch

Router business-grade + 24-port switch (managed/smart).

Wireless access

Dual-band access point for mobile customers.

Cabling & accessories

Cat6 UTP, RJ45, trunking, surge protection.

For the presentation, emphasize this: LAN for workstations (performance), WiFi for mobile users (convenience), and a core switch (manageability).

Proposed software

Operating system

Windows clients for broad application and game compatibility.

Session / billing

Tracks usage time, logins, and payments automatically.

Security

Endpoint protection plus baseline policies (auto-restore, locked settings).

Productivity

Browser, PDF reader, office suite, and printer utilities.
