Network Topology & Design

Device, topology, media komunikasi, IP addressing, dan internet access.

Proposed Topology

CyberCafe Xpress menggunakan Star Topology dengan switch sebagai pusat sambungan. Reka bentuk ini dipilih kerana stabil, mudah diurus, dan senang troubleshooting jika berlaku masalah pada mana-mana workstation.

Internet (ISP Fibre)
Unifi Fibre (cadangan)
Router
NAT • DHCP • Basic firewall
Managed Switch (Core)
24-port • VLAN optional
Access Point
WiFi untuk mobile users
Client Workstations
10–20 PCs (scalable) via Cat6

Nota: Diagram Packet Tracer akan digunakan dalam video untuk tunjuk sambungan sebenar.

Communication Media

  • UTP Cat6 untuk sambungan workstation ke switch
  • RJ45 connectors + trunking (cable management)
  • WiFi dual-band untuk phone/laptop

Internet Access

Cadangan: Unifi Fibre kerana stabil untuk gaming/streaming, latency lebih baik, dan sesuai untuk penggunaan ramai pengguna serentak.

IP Addressing Plan (Sample)

Menggunakan private IP untuk LAN. Router jadi default gateway.

Device IP Method
Router (Gateway) 192.168.10.1 Static
Switch (Mgmt) 192.168.10.2 Static
Access Point 192.168.10.3 Static
Client PCs 192.168.10.50 – 192.168.10.200 DHCP

Subnet mask: 255.255.255.0 (/24). DNS boleh guna ISP DNS atau public DNS.

Security & Management (Ringkas)

  • Basic firewall rules pada router
  • Guest WiFi diasingkan (optional VLAN)
  • Admin access hanya untuk staff
  • Backup config untuk router/switch
  • Content filtering (optional) ikut polisi premis
