Network Design

Topology, Media, IP Addressing & Internet Access

Cadangan reka bentuk rangkaian yang sesuai untuk operasi cyber café dalam shop lot 15’ × 25’.

Proposed Topology

Star topology dicadangkan kerana setiap workstation disambungkan ke switch sebagai pusat (core). Struktur ini mengurangkan gangguan keseluruhan sistem apabila satu workstation bermasalah dan memudahkan proses penyelenggaraan.

Internet Access

Preferred Option
Fibre Broadband
  • Prestasi stabil untuk penggunaan serentak
  • Latency rendah untuk gaming
  • Menyokong streaming dan kerja online

Devices

IP Addressing Plan

Skim IP private digunakan untuk LAN. Peranti core menggunakan static IP bagi memudahkan pengurusan, manakala workstation pelanggan menggunakan DHCP untuk operasi yang lebih efisien.

Device IP Address Method Role
Router (Default Gateway) 192.168.10.1 Static Gateway
Switch (Management) 192.168.10.2 Static Core
Access Point 192.168.10.3 Static WiFi
Client PCs 192.168.10.50 – 192.168.10.200 DHCP Users
Subnet Mask
255.255.255.0 (/24)
DNS
ISP DNS / Public DNS
DHCP Scope
