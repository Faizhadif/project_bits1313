Proposed star topology (simple and defensible)

A star topology suits a cyber café because every workstation connects to a core switch. If one workstation has an issue, it does not affect other workstations, and troubleshooting becomes more straightforward.

Router (Internet Gateway)

NAT, basic firewalling, optional DHCP, and outbound routing.

Core Switch (24-Port)

The star topology center. Supports port management, optional VLANs, and monitoring.

Workstations (10–20)

Wired LAN for performance. Apply policies and restore profiles.

Access Point (WiFi)

Dedicated WiFi for mobile users (optional VLAN).

During the presentation, emphasize the “single point of management”: the core switch becomes the central point for monitoring, optional bandwidth limits, and isolating issues. It looks professional while remaining simple to implement.

Security & manageability

Basic firewall rules
Block inbound, allow outbound, limit admin access to router UI.
Segmentation (optional)
Separate staff, workstations, and WiFi to reduce the blast radius.
QoS / bandwidth
Prioritise gaming + browsing, limit large downloads (optional).
